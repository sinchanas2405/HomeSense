# HomeSense project report
## Abstract
HomeSense is a full-stack web application for explainable preliminary diagnosis of smart-home device symptoms.
## Objectives
1. Maintain user and device records.
2. Represent troubleshooting knowledge as IF–THEN rules.
3. Demonstrate forward and backward chaining and propositional resolution.
4. Provide an explanation trace and safe next steps.
## Architecture
React/Vite frontend → Flask REST API → SQLite database and Python AI engine.
## Limitations
The knowledge base is illustrative and not clinically, electrically or manufacturer validated. Real deployments require expert-verified rules, testing, privacy review and secure production configuration.
